{{- /* Returns target="_blank" rel="noopener" as a trusted attribute set when the URL leaves this site, and an empty string when it does not. It has to `return` a safeHTMLAttr rather than print: Go's templates refuse a partial's plain output in attribute position and emit "zgotmplz" instead. safeHTMLAttr on the empty case too, for the same reason. Note the space before the call: … nav.js repeats the pass at runtime for any anchor added later that forgets this partial. */ -}} {{- $attrs := safeHTMLAttr "" -}} {{- $u := urls.Parse . -}} {{- $host := urls.Parse site.BaseURL -}} {{- if and $u.Host (ne $u.Host $host.Host) -}} {{- $attrs = safeHTMLAttr `target="_blank" rel="noopener"` -}} {{- end -}} {{- return $attrs -}}
